## 📌 About This Repository

This repository contains my journey of learning and practicing **Data Structures & Algorithms (DSA)**.

The main goal is to understand how different data structures work internally, learn how to implement them from scratch, analyze their efficiency, and solve practical programming problems using the right algorithm or data structure.

This repository will gradually grow from **basic programming concepts** to **advanced data structures, algorithms, problem-solving techniques, and optimization**.

### 🎯 Main Objectives

- Understand the fundamentals of Data Structures
- Learn how different data structures work internally
- Implement data structures from scratch
- Understand time and space complexity
- Practice algorithmic problem solving
- Learn searching and sorting techniques
- Master recursion and problem-solving patterns
- Understand trees and graphs
- Practice dynamic programming
- Improve competitive programming skills
- Build a strong foundation for software engineering interviews

# 📊 Complexity Analysis

Every major implementation should focus on understanding:

### Time Complexity

How the running time of an algorithm grows as the input size increases.

### Space Complexity

How much additional memory an algorithm requires.

### Common Complexities

```text
O(1)          Constant
O(log n)      Logarithmic
O(n)          Linear
O(n log n)    Linearithmic
O(n²)         Quadratic
O(2ⁿ)         Exponential
O(n!)         Factorial
```
